# Brent Crude Oil Price Forecasting (ENVS456)

Monthly Brent crude forecasting: an **AR(12)** model (the original ENVS456 coursework model) compared with
baselines and alternative time-series models on **real prices**, using a **rolling-origin backtest** and
**Diebold-Mariano** significance tests. Includes an interactive Plotly dashboard and a FastAPI service.

How to read it: commodity prices are close to a random walk, so the **naive forecast (next month = this
month)** is the benchmark every model has to beat. A model only counts as better if Diebold-Mariano says the
improvement is significant (✓).

## What the project does

| Part | File | |
|---|---|---|
| Data | `oilcast/data.py` | Downloads monthly Brent (USD/bbl) from the US EIA (`RBRTE`), falling back to FRED `POILBREUSDM` and then the same IMF series via DBnomics; skips any source more than 9 months out of date, refreshes a stale cache automatically and records the source used in `data/brent_source.txt`; validates it (no duplicate or missing months, positive prices) and caches it to `data/` |
| Models | `oilcast/models.py` | Naive, drift, seasonal naive, **AR(12) on levels** (original), AR on log-returns with AIC lag selection, ARIMA(1,1,1), damped-trend ETS |
| Backtest | `oilcast/backtest.py` | Expanding-window rolling origin (each model trained only on data before the origin), horizons 1/3/6/12 months, RMSE / MAE / MAPE, Diebold-Mariano vs naive with Harvey-Leybourne-Newbold correction |
| Original AR(12) pipeline | `oilcast/ar12_model.py` | ADF stationarity test, AR(12) fit, 95% forecast intervals |
| Dashboard | `oilcast/dashboard.py` | Plotly HTML: history + forecast, relative RMSE by model and horizon |
| API | `oilcast/api.py` | `POST /api/v1/forecast-oil` with input validation (gaps, duplicates, short series) |

## Run

```bash
pip install -r requirements.txt
python -m oilcast.run            # real data: backtest, forecast, results/backtest.md, output/dashboard.html, README
python -m oilcast.run --synthetic   # offline demo (synthetic series, clearly labelled)
python -m pytest -q
uvicorn oilcast.api:app --reload
```

## Review notes (Nov 2026)

Changes made when this project was reviewed and upgraded:

- **Crash fixed:** `AutoReg(..., old_names=False)` fails on statsmodels ≥ 0.14 (3 of 5 tests failed).
- **Circular evaluation removed:** the original data were *generated by an AR(12) process*, so an AR(12) fitting
  them well proved nothing. All reported results now use real FRED prices; the synthetic series remains only as
  an offline demo and is labelled as such.
- **Single 12-month split replaced** by a 60-origin rolling backtest with baselines and significance tests.
- **Input validation:** gaps and duplicate months are rejected instead of silently becoming NaN after `asfreq`.

Data: U.S. Energy Information Administration, Europe Brent Spot Price FOB (RBRTE); fallbacks: IMF Primary Commodity Prices, Global price of Brent Crude, via FRED [POILBREUSDM] (Federal Reserve Bank of St. Louis) or DBnomics. The source used for the published results is named in the results section.
